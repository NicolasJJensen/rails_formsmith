# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added

- Shallow, deep, and adapter-defined defaults merging, configurable per builder,
  form, or registration, with nested-form inheritance.
- Raw-argument registrations for buttons, actions, and composite components.
- Support for registering label, hidden field, button, and submit helpers.

### Changed

- Expanded the README with merge policies, adapter contracts, raw helpers, and
  fields without corresponding model attributes.
